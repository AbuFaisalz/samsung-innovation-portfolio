# Source and proposal notes

This academic portfolio translates the user-supplied Team 2 board TEMPLATE - Copy.pdf into a public, buildless website. It is not an official Samsung publication.

Source: 2036 Open Homes, Smaller Screens scenario; €1,200M annual innovation planning proxy; H1 €823M, H2 €235M; qualitative reference-company learning. Financial figures are board-reported and not independently verified.

Derived: H3 €142M = 1200 - 823 - 235; precise horizon shares and financial ratios. Source percentage labels were rounded and do not exactly match source amounts.

Proposed with user approval: all nine initiative definitions and allocations, indicative 2026–2036 development windows, outcome measures and release gates. No numerical ROI forecasts are invented. Funding scenarios scale the annual portfolio proportionally. Roadmap windows are not a cumulative capital-spend plan.

Original PDF, portraits and six-person roster are excluded from public publication. The footer follows the user's five-name instruction.

Implementation: static HTML/CSS/JS; no backend, analytics, API keys or third-party runtime requests. The locally served Inter font is licensed under the included SIL Open Font License. Theme preference is stored only in the visitor's browser and gracefully degrades without storage.

Checks: Node syntax and assert-based portfolio reconciliation at 17 funding levels; Chrome desktop at 1440 and 1154, mobile at 390; both themes; filters/search/empty reset, details, budget controls, sorting and timeline controls. Impeccable detector ran once; small-text findings were corrected. Static contrast warnings mixed print and dark-mode tokens; actual browser tokens were inspected. Independent reviewer returned ship. Mobile full-page capture was unavailable; individual mobile viewport captures were reviewed.
